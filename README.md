# DeepSkyMath

The DSTmath library of the DeepSky Project: the mathematical, array and geometry tools shared by the DeepSky libraries and tools.

## Building

Requires GSL and Boost.

```bash
git submodule update --init --recursive
cmake .
make -j
make install
```
